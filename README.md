**Analysis and Detection of Threats in Cloud Environments Using Machine Learning**  
Developed an anomaly detection model achieving **80% accuracy** with Random Forest.

This academic project, completed during my Cybersecurity & Cloud Computing studies at ENSAM Casablanca, focuses on identifying suspicious activities and threats in cloud logs using machine learning techniques. Ideal for enhancing visibility and security in AWS, Azure, or hybrid cloud setups.

## 🚀 Key Features
- Anomaly detection in cloud activity logs
- Trained models: Random Forest (primary – 80% accuracy), with comparisons to other algorithms
- Data preprocessing, feature engineering, and model evaluation
- Visualization of results and metrics
- Easy-to-run Jupyter notebooks or scripts for experimentation

## 🛠️ Technologies Used
- **Language**: Python
- **Core Libraries**:
  - `scikit-learn` (Random Forest, other classifiers)
  - `pandas` (data manipulation)
  - `numpy` (numerical operations)
  - `matplotlib` / `seaborn` (visualizations)
- **Dataset**: Synthetic or public cloud security logs (e.g., inspired by real-world scenarios)
